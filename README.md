# Django To-Do List Application

A clean, responsive To-Do List application built with the Django web framework. This project focuses on CRUD (Create, Read, Update, Delete) functionality and user authentication.

## Features
* **User Authentication:** Secure signup and login system.
* **Task Management:** Create, edit, and delete tasks.
* **Status Tracking:** Mark tasks as complete or pending.
* **Mobile Responsive:** Designed to work across different screen sizes.

## Tech Stack
* **Backend:** Python / Django
* **Database:** SQLite (Development)
* **Frontend:** HTML / CSS

## How to Run Locally
1. Clone the repository.
2. Create a virtual environment: `python -m venv django-env`
3. Activate the environment and install Django.
4. Run migrations: `python manage.py migrate`
5. Start the server: `python manage.py runserver`
